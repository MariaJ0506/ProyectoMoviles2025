# ProyectoMoviles2025

AthleteSteps

AthleteSteps es una app para planificar, ejecutar y medir las rutinas de ejercicios enfocado en las metas personales. Esta permite crear, modificar y eliminar ejercicios, organizar rutinas por días o meses para trabajar diferentes grupos musculares. 
Permite llevar una métrica sobre las repeticiones, series, peso, tiempo y distancia.
Tiene integrado un módulo de Metas y un tablero donde marca el progreso de cada persona mostrando gráficos cada mes para visualizar los avances. 
La experiencia de adapta completamente al perfil de usuario mediante las sugerencias y recomendaciones sobre carga progresiva a nivel básico.
